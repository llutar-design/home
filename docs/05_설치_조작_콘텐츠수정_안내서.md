# 설치·조작·콘텐츠 수정 안내서

## 0. 웹에서 바로 실행 (설치 없음)

1. 선생님이 알려 준 주소를 Chrome·Edge·Whale에서 엽니다. 처음에는 약 39MB를 내려받으므로 잠시 기다립니다(다음부터는 브라우저에 저장된 파일을 씁니다).
2. 웹 버전의 저장 위치는 Windows 버전과 다릅니다.

| 내용 | 웹 버전에서 |
|---|---|
| 진행 기록·설정·교사 수정 내용·사진 | **그 컴퓨터, 그 브라우저 안**에 저장됩니다. 다른 컴퓨터나 다른 브라우저에서는 이어 할 수 없습니다. 브라우저의 '인터넷 사용 기록(쿠키·사이트 데이터) 삭제'나 시크릿 창을 쓰면 기록이 사라집니다. |
| 소개 카드 PNG, 학습 기록 텍스트 | 브라우저 **다운로드**로 받습니다(보통 '다운로드' 폴더). |
| 인쇄하기 | 새 탭에 카드가 열리고 인쇄 창이 뜹니다. 팝업이 막히면 'PNG로 저장' 후 인쇄해 주세요. |

- 웹 버전에는 '끝내기' 버튼이 없습니다. 탭을 닫으면 됩니다(진행은 자동 저장).
- 웹 버전도 계정·실명·위치 정보·외부 분석 서비스를 쓰지 않습니다. 게임 파일을 내려받은 뒤에는 서버로 아무것도 보내지 않습니다.
- 학교 컴퓨터의 그래픽 드라이버가 오래되어 WebGL 2를 쓸 수 없으면 실행되지 않습니다. 이때는 Windows 버전을 쓰세요.

### GitHub에 올리는 방법

`tools/build_web.ps1` → `tools/make_web_upload.ps1` 순서로 실행하면 **`GitHub_배포/`** 폴더가 만들어집니다(파일 17개, 가장 큰 파일 약 10MB). 맨 위에 웹 게임, `docs/`에 교사용 문서, `README.md`에 저장소 설명이 들어 있습니다. 엔진 파일은 `index.wasm.gz`로 압축되어 있고 브라우저가 열 때 스스로 풉니다.

1. github.com → **New repository** → 이름 입력, **Public** → Create repository
2. **uploading an existing file** → `GitHub_배포` 폴더를 열고 **안의 파일과 `docs` 폴더를 모두 선택**해 끌어다 놓기 → **Commit changes**
3. **Settings → Pages** → Source: **Deploy from a branch**, Branch: **main**, 폴더: **/(root)** → Save
4. 1~2분 뒤 `https://아이디.github.io/저장소이름/`에서 실행. 학생 활동지: 그 주소 뒤에 `docs/03_학생용_활동지.html`
5. Windows 실행 파일(약 105MB)은 저장소에 넣지 말고 **Releases → Draft a new release**에 첨부하세요.

내용을 고친 뒤에는 같은 순서로 폴더를 다시 만들고, 파일을 다시 올리면 1~2분 뒤 자동으로 다시 게시됩니다. 스레드를 쓰지 않는 방식으로 내보내므로 서버 헤더 설정은 필요 없습니다. Vercel을 쓸 때는 이 저장소를 Vercel에서 Import 하고 Framework Preset을 **Other**로 두면 됩니다.

## 1. 설치와 실행 (Windows)

1. `build/windows/GyuamExplorers.exe` 파일 하나를 학생 컴퓨터에 복사합니다(설치 과정 없음, 인터넷 필요 없음).
2. 두 번 눌러 실행합니다.
   - 서명되지 않은 실행 파일이라 처음 실행할 때 Windows SmartScreen 경고가 나올 수 있습니다. '추가 정보 → 실행'을 누르세요. 학교 보안 정책에 따라 관리자 승인이 필요할 수 있습니다.
3. 필요한 환경: Windows 10/11 64비트, OpenGL 3.3을 지원하는 그래픽(최근 10년 안의 노트북·데스크톱 대부분).

### 저장 위치

| 내용 | 위치 |
|---|---|
| 진행 기록(슬롯 3개), 설정, 교사 수정 내용, 탐험 사진 | `%APPDATA%\Godot\app_userdata\규암마을 탐험대\` (게임 이름을 바꾼 뒤에도 기존 기록을 이어 쓰도록 예전 폴더 이름을 그대로 씀) |
| 소개 카드 PNG·인쇄용 파일, 학습 기록 텍스트 | `문서\부여마을탐험대\` |

- 계정·실명·위치 정보·외부 분석 서비스를 쓰지 않습니다. 학생은 '탐험대 이름'만 정합니다.
- 외부 생성형 AI 없이 대화·미션·소개 카드가 모두 작동합니다.

| 사진 보기 | — | '사진첩' 버튼 → 설명 고치기, 소개 카드에 쓸 사진 정하기, 내려받기, 지우기 |

### 사진 활용

- 사진을 찍으면 게임이 카메라 앞 가까이에 있는 장소·주민·특산품·축제를 알아보고 '사진 속에서 찾은 것'으로 적어 줍니다.
- 학생은 "무엇을 찍었나요?"에서 낱말을 고르고 한 줄 설명을 씁니다(정답 판정 없음). 관찰한 것을 자기 말로 남기는 활동입니다.
- **사진 찾기 놀이(선택)**: 옛날 모습이 남은 곳, 마을에서 일하는 사람, 우리 마을 특산품, 강·들판·나무, 함께 모인 사람들. 직접 찍은 사진만 셉니다. 미션 진행을 막지 않고 점수도 없습니다. 항목은 `content.json`의 `photo_challenges`에서 바꿀 수 있습니다.
- '소개 카드에 쓸 사진'으로 정한 사진과 그 설명이 소개 카드에 들어갑니다.
- 교사 학습 기록에 사진 설명·고른 낱말·사진 찾기 놀이 결과가 남습니다.
- 사진은 슬롯마다 30장까지 보관하며, 넘치면 설명이 없는 자동 사진부터 지웁니다.

- **점프가 없습니다.** 수북정 언덕도 경사로로 올라갑니다.
- 시간 제한이 없고, 틀려도 점수를 깎지 않습니다. 힌트를 보고 다시 고릅니다.
- 활동 창의 '읽어 주기' 버튼은 컴퓨터에 한국어 음성이 있을 때 글을 읽어 줍니다. 음성이 없으면 글 안내만으로 모두 할 수 있습니다.

### 학생 설정 (화면 오른쪽 위 '설정')

- 글자 크기: 보통 / 크게 / 아주 크게
- 카메라 돌리는 빠르기
- 화면 움직임 줄이기(안내 표시가 흔들리거나 회전하지 않음, 특산품 모형 자동 회전 끄기)
- 음성 안내, 효과음
- 짝 활동 안내(미션마다 '조작하는 사람 ↔ 관찰하고 이야기하는 사람' 바꾸기 안내)

## 3. 선생님 설정

처음 화면의 **'선생님'** 버튼 → 간단한 덧셈 답 입력(학생이 실수로 들어가지 않도록) → 탭을 골라 수정 → **저장하기**.

| 탭 | 바꿀 수 있는 것 |
|---|---|
| 미션 | 사용할 미션 켜기/끄기, 미션을 마치는 데 필요한 장소·주민·특산품 수 |
| 탐험 장소 | 관찰할 장소 켜기/끄기, 장소 이름·설명·관찰 낱말·실제 정보 |
| 특산품 | 사용 여부, 임시 아이템 표시, 이름·특징·지역 관계·설명·질문·보기·정답·힌트·출처 |
| 주민 대사 | 사용 여부, 이름·하는 일·첫인사·질문 4가지에 대한 대답 |
| 축제 | 행사 이름·안내 문구·실제 축제 참고 정보, 활동 켜기/끄기(안내판·바구니·정리하기), 질문 문구 |
| 교과서 연계 | 교과서 이름, 연계 단원·활동, 확인 완료 표시, 화면에 보일 구성 표시 |
| 화면·소리 | 안내 글자 크기, 음성·효과음, 화면 움직임 줄이기, 짝 활동 안내 |
| 학습 기록 | 슬롯별 참고 기록 보기·파일로 저장(문서\부여마을탐험대), 슬롯 초기화, 모든 기록 초기화(두 번 눌러야 동작) |

- 바꾼 내용은 `teacher_overrides.json`에 저장되고 기본 콘텐츠는 그대로 남습니다. '기본 콘텐츠로 되돌리기'를 두 번 누르면 처음 상태로 돌아갑니다.
- 장소의 **지도 위치**와 3D 모양은 설정에서 바꿀 수 없습니다(코드 `scripts/world/world_builder.gd`).

## 4. 콘텐츠 파일로 고치기 (여러 교실에 같은 내용 배포)

모든 교육 콘텐츠는 코드와 분리된 `game/data/content.json` 한 파일에 있습니다.

| 항목 | 내용 |
|---|---|
| `meta` | 제목, 구성 표시(`edu_status`), 지도 안내(`map_notice`), 교과서 정보(`textbook`) |
| `rules` | `need_places`, `need_npcs`, `need_specialties` |
| `missions` | 5개 미션(순서 고정), `enabled`, 제목, 소개, 배움 확인 |
| `places` | 장소: `observe`(관찰 미션 사용), `is_real_name`, `region`(gyuam/border/game), `fact`, `words`, `real_ref` |
| `questions` | 주민에게 묻는 질문 4가지 |
| `npcs` | 가상 주민: 이름, `role`, `greeting`, `answers`(job/tools/help/we_can), `look`(겉모습) |
| `specialties` | 특산품: `scope`(gyuam/buyeo), `scope_label`, `feature`, `relation`, `desc`, `quiz`, `provisional`, `source` |
| `festival` | 가상 행사 이름, 활동, 안내판 정답·힌트, 정리하기 물건, 질문 |
| `card` | 소개 카드 문장 틀. `{}` 자리에 낱말이 들어가고 `{을/를}`, `{이/가}`, `{이에요/예요}`는 받침에 맞게 자동으로 고릅니다 |

수정 후 배포 방법:
1. Godot 4.7 편집기로 `game/project.godot`를 열어 실행(F5)해 확인합니다.
2. 프로젝트 → 내보내기 → 'Windows Desktop' → 프로젝트 내보내기. (명령줄: `Godot --headless --path game --export-release "Windows Desktop" ../build/windows/GyuamExplorers.exe`)
3. 특산품 모형은 `grape`, `melon`, `watermelon`, `chestnut`만 따로 만들어져 있습니다. 새 id를 넣으면 '임시' 상자 모형과 물음표 그림으로 보입니다. 과일 체험 마당에는 앞에서부터 4개까지 놓입니다.

## 5. 개발자용 확인 명령

```text
# 모든 스크립트 문법 확인
Godot --headless --path game res://tests/check.tscn

# 전체 흐름 자동 시험 (창이 잠깐 열림, 슬롯 3 사용 후 지움)
Godot --path game -- --selftest --out=<결과 폴더>
Godot --path game -- --selftest --cleanup --out=<결과 폴더>   # '정리하기' 활동을 켠 경우

# 내보낸 실행 파일 확인 (처음 화면을 PNG로 저장하고 끝남)
GyuamExplorers.exe -- --smoke=C:/temp/shot.png
```

