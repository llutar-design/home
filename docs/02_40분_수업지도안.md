# 40분 수업 지도안 — 부여마을탐험대

- **대상**: 초등학교 2학년
- **구성**: 교과서 확인 전 임시 교육 구성 (교과서 단원과의 정확한 연결은 교과서 확인 뒤 보완)
- **준비물**: 게임이 설치된 Windows 컴퓨터(1~2명당 1대), 헤드폰(음성 안내를 쓸 때), 학생용 활동지, 필요하면 프린터
- **수업 전 확인**: 슬롯이 비어 있는지(선생님 설정 > 학습 기록), 음성 안내가 나오는지, 글자 크기가 알맞은지

> 한 번의 탐험(미션 1~5)은 15~20분 안에 마칠 수 있게 설계했지만, 실제 2학년 학생과 시간을 재 보지는 않았습니다. 첫 수업에서는 미션 1~3까지만 하고 다음 시간에 이어 하는 방법도 좋습니다(언제든 저장되고 이어 할 수 있습니다).

## 흐름

| 시간 | 단계 | 교사 활동 | 학생 활동 | 자료·유의점 |
|---|---|---|---|---|
| 0~5분 | **알고 있는 마을 모습 이야기하기** | "우리 마을(규암면)에서 가 본 곳은 어디인가요?", "마을에서 일하는 사람을 본 적이 있나요?" 하고 묻습니다. 게임 지도 화면을 보여 주며 "규암면을 참고하여 재구성한 학습용 지도"라는 점을 알려 줍니다. | 가 본 장소, 아는 사람, 먹어 본 과일을 자유롭게 말합니다. | 실제 장소(수북정, 백제문화단지의 사비궁·능사, 백마강, 강 건너 부여읍의 정림사지·부소산성·궁남지·국립부여박물관)와 게임용 장소(옛 골목길, 마을 쉼터, 과일 체험 마당, 한마당 광장, 아울렛 쇼핑거리)를 구분하고, 백마강 서쪽이 규암면, 동쪽이 부여읍이라는 점을 짚어 줍니다. 40분 수업에서는 규암면 안 장소 위주로 하고, 부여읍은 다음 시간이나 더 해 보기 활동으로 남겨도 됩니다. |
| 5~25분 | **게임 탐험하기** | 탐험대 이름을 짓게 합니다(실명 쓰지 않기). 돌아다니며 '관찰하기 → 질문하기 → 알아보기'를 하도록 돕고, 막힌 학생에게는 노란 화살표와 '안내소로' 버튼을 알려 줍니다. | 미션 1~4를 진행합니다. 활동지 1~4번에 짧게 적거나 그립니다. | 시간 제한이 없습니다. 빨리 하는 것보다 자세히 보는 것이 중요하다고 말해 줍니다. 짝 활동이면 미션마다 역할을 바꿉니다(아래 참고). |
| 25~35분 | **마을 소개 카드 만들기와 친구에게 소개하기** | 미션 5(소개 카드)를 안내합니다. 문장 틀과 낱말 고르기를 쓰되, 자기 말로 한 문장 더 써 보도록 격려합니다. | 사진·장소·주민·특산품·축제에서 도운 일을 골라 카드를 만들고, 짝이나 모둠 친구에게 카드를 보여 주며 소개합니다. | 'PNG로 저장' 또는 '인쇄하기'. 카드 글은 학생이 고르거나 쓴 내용으로만 만들어집니다. |
| 35~40분 | **새롭게 알게 된 점 나누기** | "새롭게 알게 된 것은 무엇인가요?", "마을 사람들은 서로 어떻게 돕고 있나요?" 하고 묻습니다. | 활동지 6번을 쓰고 발표합니다. | 미션 완료 여부보다 학생의 말과 카드 내용을 관찰합니다. |

## 두 학생이 한 기기를 쓸 때

- **조작하는 사람**: 키보드·마우스로 걷고 버튼을 누릅니다.
- **관찰하고 이야기하는 사람**: 화면을 보며 "저기 돋보기가 있어!", "포도는 송이송이 모여 있네" 하고 말하고, 무엇을 고를지 함께 정합니다.
- 미션 하나를 마칠 때마다 역할을 바꿉니다. **설정 > 짝 활동 안내**를 켜면 미션 완료 창에 "역할을 바꿔요!"가 나오고, 화면 왼쪽 위에 지금 누가 조작할 차례인지 표시됩니다.

## 관찰 기록 (선생님용)

| 관찰 항목 | 근거로 볼 것 | 메모 |
|---|---|---|
| 장소의 특징을 말하는가? | 관찰 낱말·직접 쓴 말, 발표 | |
| 주민이 하는 일을 설명하는가? | 물어본 질문, 연결하기, 발표 | |
| 특산품의 특징을 알아보는가? | 도감, 활동지 3번 | |
| 함께 사용하는 공간에서 지킬 행동을 생각하는가? | 약속 고르기, 축제 돌아보기 | |
| 발견한 내용을 자기 말로 소개하는가? | 소개 카드, 친구에게 소개하는 모습 | |

※ 게임의 미션 완료 표시만으로 학습 목표 달성을 판정하지 않습니다.
