# 부여마을탐험대 (웹 버전)

초등학교 2학년 마을 학습용 탐험 게임입니다. 충청남도 부여군 규암면을 중심으로 장소·사람·특산품·축제·부여 10경을 알아봅니다.
브라우저(Chrome·Edge·Whale 최신 버전)에서 바로 실행됩니다. 처음 열 때 약 11MB를 내려받습니다.

- **게임 주소**: 이 저장소의 GitHub Pages 주소 (Settings → Pages에 표시)
- 교과서 확인 전 임시 교육 구성 · 규암면(과 강 건너 부여읍 일부)을 참고하여 재구성한 학습용 지도
- 진행 기록은 그 컴퓨터의 그 브라우저 안에만 저장됩니다. 계정·실명·위치 정보·외부 분석 서비스를 쓰지 않습니다.
